**원문**: [jp.ign.com](https://jp.ign.com/cedec-2021/54158/feature/elden-ring-cedec2021) — あでゆ, IGN Japan, 2021-08-27. 강연 「『情報地図』で俯瞰するマップ情報の可視化 - マップ全体を把握するための開発支援ツール」(CEDEC 2021), 발표 프로그래머 川崎涼太·古田島裕斗. (한국어 정리는 IGN Japan 원문 + [vgbaike 중국어 번역](https://www.vgbaike.com/elden_ring/baike7533) 교차 대조. 중국어판 제목 "至高의 툴"은 헤드라인 수사이고 툴 정식 명칭은 '情報地図'. 중국어판 개발자명 "川崎良太"는 원문 川崎**涼**太의 오기)

프롬소프트웨어가 오픈월드(엘든 링)로 가며 겪은 "맵이 너무 커져 아무도 전체를 못 파악하고 데이터 추출이 속인화(属人化)됨" 문제를 풀기 위해 만든 사내 개발지원 웹 툴 '情報地図'. AAA 스튜디오의 *데이터 주도 레벨디자인 계측 도구*를 드물게 상세 공개한 1차 사료. (강연에 쓴 맵은 강연용 별도 제작, 개발 중 신작과 무관)

> 💡 **핵심 인사이트:** [[data-driven-development|데이터 기반 개발]]이 *의사결정 방법론*이라면, 情報地図는 그걸 가능케 하는 **계측·툴링 인프라**다. 프롬은 텔레메트리(플레이 경로·데스·아이템 획득·히트맵)를 조감 지도로 시각화해, *"같은 개발 기간에 더 깊은 레벨디자인"*을 달성했다고 밝혔다. 인디의 [[gdc19-slay-the-spire-metrics|Slay the Spire 메트릭 밸런싱]]에 대응하는 AAA 카운터파트.

## 툴 개요

- **Leaflet**(웹 지도 라이브러리) 기반 웹앱. 일반 게임 맵처럼 팬·줌, 노란 마커 클릭 시 지점 상세
- **그리드·에어리어 정보** 오버레이 → 어느 지점이 어느 구역인지, 적 배치 밀도 한눈에
- **카테고리 체크박스 필터**(예: 보스만 표시), **키워드 검색**(특정 적 배치 위치, 드랍 아이템명으로 해당 적 위치), **해시태그 태깅 + 태그 기반 필터**
- **실기 게임 연동**: 개발 중 게임 기동 시 클릭 한 번으로 해당 위치 워프 → AI 거동 확인·버그 체크 효율화
- **소울 시리즈 메시지식 메모**: 배치 관련 공유 메모를 남기고 "마커 URL 복사"로 채팅에 링크 → 클릭만으로 수정 의뢰·공유

## 데이터 주도 레벨디자인 기능

- **플레이 기록 재생**: 플레이어 이동 루트, 게임오버 지점, 중요 아이템 획득 시점을 동선으로 확인. 청색 핀 + 시계열 재생, 사망·보스격파 시 마커 자동 생성
- **히트맵**: 자주 지나는 길(적·황) vs 한 번만 지난 길(청) 시각화 → *플레이어 유도 지표*로 활용, 중요 아이템에 안 들르면 배치 재조정 (→ [[player-guidance-design|플레이어 유도 설계]]의 계측 근거)
- **프로그래머용 부하 히트맵**: 동작이 무거워지는 지점 파악, 오브젝트·적 과다로 메모리 초과 지점 자동 핀 → 맵 담당자가 수정 지점 즉시 식별
- **다중 플레이어 통계**: 여러 플레이로그로 드랍 아이템 획득 기대값 적정성 확인, 총 사망 횟수로 적 강도 조정
- **모듈화**: 각 기능이 모듈이라 프로젝트별로 필요/불필요 기능을 분리, 장르별 범용 + 프로젝트 요건별 전문 기능 제공

> 💡 프롬의 "탁월한 레벨디자인"은 미야자키의 감각뿐 아니라 *이런 사내 툴·엔지니어링 인프라*가 뒷받침한다. 툴 개발자·개발환경 엔지니어라는 "뒷단"의 존재가 AAA 품질의 실체라는 점을 보여주는 사례.
