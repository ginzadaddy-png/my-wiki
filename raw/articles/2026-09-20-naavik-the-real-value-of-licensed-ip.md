## 문제 제기

Star Wars Zero Company는 평단·유저 호평(VG Insights 기준 80만 장 이상, 매출 $36M)에도 출시 전 팀의 80%가 무급휴직 상태였다는 사실이 공동창업자 간 소송 법원 제출 서류에서 드러났다(손해배상 $20M 청구 소송이 병행 중이었다는 사정은 감안 필요).

이 사례에서 출발한 질문: **외부 IP를 라이선스하면 스튜디오는 정확히 무엇을 얻고, 상업적으로 무엇을 기대할 수 있는가?**

업계 통념은 IP가 가시성·노출·기성 오디언스를 준다는 것:
- Karl Slatoff (Take-Two 사장, 2024 Q2 실적발표): 주목받기 어려운 시장에서 알려진 브랜드는 주목을 얻는 방법이라는 사실은 부정할 수 없다
- Laura Miele (EA COO, 2023 Q2 실적발표): 라이선스 IP는 확장·다변화·저변 확대에 지극히 중요한 요소

반대 흐름도 존재:
- Andrew Wilson (EA CEO, 2024): 변화하는 산업에서 성공하리라 보지 않는 라이선스 IP 개발에서 손을 뗀다
- Reuters 보도: 텐센트도 높은 로열티를 이유로 일부 외부 IP 딜에서 후퇴

## 방법론

IP 유형 분류:
- **Owned/Group-Controlled IP**: 퍼블리셔 또는 지배 그룹이 보유한 기존 IP (WBD의 배트맨, 유비소프트의 어쌔신 크리드)
- **External IP**: 무관한 권리자로부터 라이선스한 기존 IP (Marvel Rivals, Marvel's Spider-Man, Warhammer 40,000: Space Marine). **동일 게임 시리즈의 속편은 제외** — 라이선스 IP의 가치와 전작이 만든 브랜드 자산을 혼동하지 않기 위함
- **External Sports IP**: 스포츠·레이싱 라이선스. 라이선싱 역학이 크게 달라 분리
- **Original IP**: 기성 오디언스·브랜드가 없는 신규 IP. 초대 어쌔신 크리드는 Original, 속편부터는 Owned. 속편 제외는 External과 동일

분석 범위:
- **External vs Original IP만 비교**, 2015~2025 출시작, 누적 판매 1만 장 미만 필터링
- 최종 표본 **13,773개 게임 (External IP 436개)**
- **연차 보정**: 2015년작은 10년치 판매를 누적했고 2025년작은 아니다. 각 출시연도의 **Original IP 중앙값을 그 해의 기준선(1.0)**으로 삼고 모든 게임을 그에 대한 배수로 측정. 2.0 = 같은 해 Original IP 중앙값의 2배 판매
- **자기 한계 명시**: 관찰 데이터다. 측정된 상승분은 External IP에 *결부된* 상업적 우위이지 라이선스 자체의 고립된 인과 효과가 아니다

## 발견 1 — External IP는 실패를 막기보다 성공을 증폭한다

누적 판매량 기준, 모든 측정 백분위에서 External IP가 Original IP를 상회:
- 10백분위 **1.23x** → 75~90백분위 **약 4x**로 격차가 상단에서 급격히 확대

단 위험 제거는 아니다:
- **External IP 하위 25%는 여전히 Original IP 중앙값보다 적게 팔렸다**
- 더 세분한 백분위 구간으로 보면: 최하단에서는 External IP 실패작과 Original IP 실패작 사이에 실질적 차이가 없음 → 우위가 계속 커지다 **70~80백분위에서 정점** → 블록버스터 규모에서는 다시 하락 (블록버스터는 이미 자체 수요가 강해서)

결론: External IP는 **실패를 구제하는 데는 약하고 성공을 증폭하는 데 강하다**.

## 발견 2 — 스위트스팟은 '훌륭한' 게임이 아니라 '좋은' 게임

Steam 리뷰 등급별로, 같은 해·같은 리뷰 등급의 Original IP 게임을 기준선으로 삼아 재분석:
- **Very Positive 등급: 중앙값 4.51x 상승** (최대)
- **Overwhelmingly Positive 등급: 2.06x** 에 그침

해석: 품질이나 바이럴만으로 자력 돌파가 일어나기 *직전* 구간, 즉 **좋지만 특출나지는 않은 게임에서 External IP의 증폭 효과가 가장 크다**.

## 발견 3 — Original IP는 더 높은 품질 기준을 넘어야 한다

리뷰 등급별로 묶되 기준선을 *그 해 Original IP 중앙값 전체*로 통일해 비교:
- **Original IP는 Very Positive를 받아야 겨우 중앙값 판매에 도달**
- **External IP는 Mixed 등급으로도 중앙값을 넘긴다**

## 발견 4 — 가격대 분포가 정반대

출시가를 상업적 야심의 프록시로 사용. VG Insights는 현재가만 제공해 IsThereAnyDeal에서 출시가 이력을 수집, 사용 가능한 데이터 약 10,400개 확보.
- **Original IP는 $10~20 구간에 고도로 집중**
- **External IP는 $40에서 정점**
- $40 초과 가격의 Original IP 게임은 비교적 매우 적음

## 발견 5 — 같은 가격대끼리 비교해도 매출 우위는 유지된다

동일 출시가 구간 + 동일 출시연도 Original IP 중앙값 대비 매출 비교:
- **30개 비교군 중 29개에서 External IP가 우위**
- 가장 일관된 상승은 **$40~50 구간, 75백분위에서 3.4x** 정점
- $60+ 구간은 기술적으로 4.0x이나 **해당 구간 External IP가 10개뿐** → 저자 스스로 "정확한 크기보다 방향성으로만 취급하라"고 단서

## 발견 6 — 매출 우위가 곧 수익성은 아니다

연도별 코호트 중앙값 → 그 중앙값들의 중앙값으로 전형적 결과 산출:
- **$50~60 가격대에서도 External IP 코호트 중앙값 Steam 매출은 $9.8M에 불과**
- 매출은 이익이 아니다. 플랫폼 수수료·개발비·마케팅비 + **라이선스 비용**을 별도 차감해야 함

양극단 사례:
- **Daedalic**: $40 구간 중앙값 수준 게임에 **개발비 $16M을 써서 매출 $9M**. 이론상 동급 Original IP 대비 2.6x를 달성했는데도 실패. 결국 게임 개발 사업 자체를 접고 25명 감원
- **Insomniac**: Marvel's Spider-Man: Miles Morales가 **총비용 $156M 대비 매출 $260M** — 증폭이 실제로 작동한 사례

로열티 영향 시뮬레이션:
- 유출된 Insomniac–Marvel 조건상 **로열티는 SKU에 따라 9~26%**
- 단순 **20% 로열티**를 매출 상승분에 적용하면 중앙값 우위가 **1.52x~2.62x → 1.22x~2.10x로 축소**

## 결론

External IP는 동급 Original IP 대비 상업적 성과를 개선한다 — 더 많이 팔리고, 더 많은 매출을 내며, 게임이 성공적일수록 그 우위가 커진다. 그러나 **실패작을 히트로 바꾸지는 못하고, 여전히 홈런이 필요하다**.

저자의 프레이밍: **External IP는 보험이 아니라 레버리지(leverage, not insurance)**. 강한 상업적 제안을 훨씬 더 가치 있게 만들지만, 기저 투자 자체를 안전하게 만들지는 못한다.

최선의 팀은 자기 운명을 통제하기 위해 여전히 자체 IP를 지향해야 한다 — 한 게임짜리 히트가 아니라 장기 사업을 짓기 위해. 다만 *"이 IP가 로열티·높아진 비용·복잡성·기대치를 상쇄할 만큼 더 많이 팔게 해줄 것인가?"*에 "예"라고 답할 수 있는 팀에게 External IP는 강력한 레버가 된다.
